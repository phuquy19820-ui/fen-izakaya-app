================================================================================
📡 4 API CHÍNH (Chi Tiết ở API.md)
================================================================================

1. POST /api/branches/create
   → Tạo chi nhánh mới

2. POST /api/bom/upload
   → Upload file BOM Excel (định lượng món ăn)

3. POST /api/cukcuk/sync
   → Đồng bộ dữ liệu bán hàng & tồn kho từ CUKCUK

4. POST /api/purchase-plans/generate
   → Tạo kế hoạch mua hàng (tự động tính toán)

================================================================================
💡 WORKFLOW (QUY TRÌNH SỬ DỤNG)
================================================================================

Step 1: Tạo Chi Nhánh
  └─→ API: POST /api/branches/create

Step 2: Upload BOM (Định Lượng Món Ăn)
  └─→ API: POST /api/bom/upload
  └─→ File Excel: [Mã Món] [Tên Món] [Giá] [NVL] [Số Lượng]

Step 3: Đồng Bộ CUKCUK (Tuỳ Chọn)
  └─→ API: POST /api/cukcuk/sync
  └─→ Lấy: Bán Hàng (7 Ngày) + Tồn Kho

Step 4: Tạo Kế Hoạch Mua Hàng
  └─→ API: POST /api/purchase-plans/generate
  └─→ Tự động tính: Nhu Cầu + Hao Hụt + An Toàn - Tồn Hiện = Số Mua

Step 5: Xem & Sửa Kế Hoạch (Frontend)
  └─→ Browser: http://localhost:3000/purchase-plan
  └─→ Sửa số mua → Lưu

Step 6: Xuất & Gửi Nhà Cung Cấp
  └─→ Export PDF/Excel
  └─→ Gửi nhà cung cấp
